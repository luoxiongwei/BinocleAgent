# 当前架构与入口（2026-10-23 重建）

> 本文为架构权威文档（原 docs/ 目录曾丢失，本版基于 2026-10-23 全量代码审阅重建）。
> 功能明细见 `docs/项目功能清单.md`；设计动机见根目录《AGENT与YOLO融合设计.md》。

## 1. 唯一生效路线

```
Vue(frontend/, :5173) / web/console.html
        │ /tasks /health /inputs /qa /chat      │ /api
        ▼                                        ▼
agent.service:app (:8000)              agent.api_web:standalone (:8010)
生产任务 API（唯一写入口）               只读控制台 API（另挂 /console 静态页）
        │
        ▼
agent.graph（LangGraph 13 节点状态机，唯一编排）
        │
        ▼
tools/（能力层，无状态） + scripts/（算法层，子进程） + libs/ultralytics（内置 YOLOv8）
        │
        ▼
results/agent/graph_runs/<task_id>/  ← graph_state.json + events.jsonl + checkpoint.sqlite
```

三层分工：
- `scripts/` 算法执行层（子进程隔离：vlm_judge / llm_judge / l1_smoke / rag_index / doctor）
- `tools/` 能力层（无状态纯函数：配准、对账、规则引擎、证据校验、模型网关）
- `agent/` 编排层（LangGraph 状态机 + FastAPI 服务 + 处置语义）

## 2. LangGraph 节点与路由（13 节点）

```
qc → perceive → detect → reconcile → verify_equipment → judge
    → {archive | manual | tip | full | plan} → human_gate → finalize
```

| 路由 | 条件 → 去向 |
|---|---|
| `route_after_qc` | 配准质检通过 → perceive；重融合一次后仍失败 → human_gate |
| `route_after_perceive` | VLM 失效 → human_gate（感知链失效禁止判"安全"） |
| `route_after_reconcile` | 对账失败 → human_gate；规划器启用时 → plan（定向重感知） |
| `route_after_judge` | 安全→archive / 低风险→tip / 高风险→full / 判不了→manual；规划器启用时 tip/full/manual 改走 plan |
| `route_after_act` | 有确定等级 → finalize；无等级/工具失败 → human_gate |

路由函数均为一等函数、可单测。`finalize`（graph.py 约 :542）是唯一写任务 status 终态的地方。

## 3. 服务入口与端口

| 服务 | 命令 | 端口 | 职责 |
|---|---|---|---|
| 生产任务服务 | `python -m uvicorn agent.service:app --port 8000` | 8000 | 任务创建/查询/事件流/重试/复核回写/验收/反馈、图对上传、对话 `/chat`、知识问答 `/qa` |
| 只读控制台 | `python -m uvicorn agent.api_web:standalone --port 8010` | 8010 | 产物/批次/待审队列只读查询，挂 `/console` 零依赖页；不调模型、无 key 可用 |
| Vue 前端 | `cd frontend && npm run dev` | 5173 | 主控制台（dev server 代理：`/api`→8010，`/tasks /health /inputs /qa /chat`→8000） |

一键三进程（Windows）：`scripts\start_debug_stack.bat`（或根目录 `启动Binocle安全日志Agent.bat`），
健康轮询等待，PID 记录在 `results/debug_stack/processes.json`；`stop / status / restart` 子命令可用。

## 4. 关键数据落点

| 路径 | 内容 |
|---|---|
| `results/agent/graph_runs/<task_id>/` | 在线研判任务产物（graph_state.json 终态、events.jsonl、checkpoint.sqlite、source/ 输入快照） |
| `results/agent/<批次>/` | CLI 批跑产物（`agent.run_all --out-root` 指定；含 summary.json） |
| `results/agent/pending_reviews.json` | 人工待审队列（前端复核台数据源） |
| `results/agent/human_archives.json` | 人工归档留痕 |
| `results/golden_set/golden_set.json` | 30 对金标真值（四级处置语义，修订走 history） |
| `results/rag_store_v2/` | RAG 向量库（BGE + BM25，`scripts/rag_index.py` 重建） |
| `data/rgbt/output/` | 用户图对落盘（规范名 rgbNN/irNN），别名表 `data/pair_aliases.json` |
| `results/fused/` `results/panels/` | 融合图与三联板缓存（活跃缓存勿清） |
| `config/agent.yaml` | 运行时配置（planner_enabled、基线路径、融合阈值） |
| `config.json` | 模型网关配置（真实 key，**严禁随包分发**，模板 config.example.json） |
